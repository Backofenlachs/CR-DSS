# Wichtige Nygard-Prinzipien

- Eine ADR beschreibt **eine einzelne Entscheidung**
- Entscheidungen sind **historische Dokumente**
- Wird eine Entscheidung geändert --> neue ADR schreiben
- Kurz und präzise halten
